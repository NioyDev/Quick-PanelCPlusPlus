# Quick Panel C ++

## Característica Y Componentes Del Panel.

- Quick Panel Lateral Izquierdo.
    - Menu
    - Aplicación En Ejecución y Ancladas.

- Quick Panel Lateral Derecho.
    - Volumen
    - Bluetooth
    - Brillo
    - Wifi
    - Batería
    - Fecha y Hora
    - Botón de Acciones del Sistema
## Cómo Compilar y Ejecutar

Este proyecto está construido con C++ y **Qt**, por lo que es multiplataforma.

### En Linux
Para compilar y probar rápidamente en la terminal:

1. Compilar el proyecto:
   ```bash
   make
   ```
2. Ejecutar la aplicación:
   ```bash
   ./main
   ```

### En Windows
Funciona nativamente. La forma más cómoda y sin configurar nada es abrir el archivo `Quick-PanelPlusPlus.pro` directamente usando el programa **Qt Creator** y presionar el botón de "Play" (Run).
